# Olahbola SEO Setup Guide - Quick Fix

## ✅ Yang Sudah Diperbaiki

1. **Sitemap & Robots URLs** - Diubah dari `https://olahbola.com` ke `https://www.olahbola.com` (dengan www)
2. **JSON-LD** - Diubah ke inline render agar bisa dibaca Googlebot saat SSR
3. **MetadataBase** - Sudah menggunakan URL dengan www

## 🚨 Masalah & Solusi

### Masalah 1: Sitemap Tidak Valid

**Error:** "Alamat peta situs tidak valid"

**Penyebab:** URL mismatch - Anda menginput `https://olahbola.com/sitemap.xml` tapi robots.txt menggunakan `https://www.olahbola.com/sitemap.xml`

**Solusi:**
- Di Google Search Console, input `https://www.olahbola.com/sitemap.xml` (dengan www)

Atau jika tetap tidak bisa:
- Buka https://www.olahbola.com/sitemap.xml di browser
- Jika bisa diakses, copy entire URL dari address bar
- Paste di Search Console

### Masalah 2: Tidak Ada Item Structured Data Terdeteksi

**Penyebab:** Structured data menggunakan client-side render (mounted check) sehingga Googlebot tidak bisa melihat saat crawl

**Solusi:**
- Sudah diubah ke inline JSON-LD render
- Deploy ulang ke Vercel

## 📋 Langkah Setup Setelah Deploy

### Langkah 1: Deploy Ulang

```bash
vercel deploy
```

### Langkah 2: Test Sitemap

Buka di browser:
```
https://www.olahbola.com/sitemap.xml
```

Harus muncul XML content. Jika 307 redirect, follow redirect - itu normal.

### Langkah 3: Submit Sitemap di Google Search Console

1. Buka https://search.google.com/search-console
2. Pilih property Olahbola
3. Menu Sitemap
4. Input: `https://www.olahbola.com/sitemap.xml`
5. Klik Submit

### Langkah 4: Test Structured Data

1. Buka https://search.google.com/test/rich-results
2. Masukkan URL artikel, contoh:
   ```
   https://www.olahbola.com/artikel/resmi-dimulai-football-city-battle-olahbola-meriah
   ```
3. Klik Test

Harus muncul **Article** schema detected.

### Langkah 5: Verify Homepage Schema

1. Buka https://search.google.com/test/rich-results
2. Masukkan: `https://www.olahbola.com/`
3. Klik Test

Harus muncul **WebSite** dan **Organization** schema.
